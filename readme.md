# Docker Multi-Container Assignment

This project demonstrates the containerization of a full-stack application consisting of a Python backend and a Node.js frontend. Through this assignment, I practiced core Docker fundamentals, focusing on how independent services interact within a managed environment.

## 🚀 Project Overview
The goal of this project was to move away from "it works on my machine" by using Docker to create a consistent environment for both the frontend and backend. 

### Key Learnings:
* **Docker Fundamentals:** Building custom images using specific Dockerfiles for different tech stacks (Python & Node.js).
* **Container Networking:** Configuring internal communication so the frontend can securely fetch data from the backend service.
* **Orchestration:** Using Docker Compose to manage the lifecycle of multiple containers simultaneously.
* **Image Management:** Tagging and pushing local images to an online repository for remote accessibility.
